# ApplySauce

A landing site for ApplySauce, an AI assistant for the job search. Built with Next.js
and TypeScript.

The page presents the product's features across the whole hunt: job discovery, ATS
scoring and prioritization, AI CV tailoring, cover letters and outreach, contact
prospecting, interview prep and tracking, career-path management, and a pipeline dashboard.

- Live demo: https://applysauce-landing.vercel.app
- Stack: Next.js (App Router), TypeScript, Tailwind CSS

```bash
npm install
npm run dev
```
